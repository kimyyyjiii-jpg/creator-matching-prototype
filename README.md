# 크리에이터 매칭 추천 프로토타입

예산·카테고리·팔로워 규모를 입력하면, 예산 안에서 집행 가능한 크리에이터를 캠페인 목적에 맞춰 추천합니다.
기획은 [PRD.md](PRD.md), 로직 흐름은 [flowchart.md](flowchart.md)를 기준으로 구현했습니다.

## 실행

빌드나 패키지 설치가 필요 없습니다. 브라우저가 CSV를 `fetch`로 읽기 때문에 로컬 서버로 열어야 합니다.

```bash
python3 -m http.server 8000
```

- 앱: http://localhost:8000/
- 로직 테스트: http://localhost:8000/tests/

## 구조

```
index.html, styles.css      화면 (입력 폼 + 결과가 한 페이지)
dummy_creators.csv          원본 데이터 (수정하지 않음)
src/
  app.js                    폼 상태, 추천 실행, 완화안 버튼 처리
  data/csv.js               CSV 파서 (BOM·따옴표 처리)
  data/dataset.js           정제, 추정 단가, 보정 평점, 지표·백분위, 태그·배지 판정 (로딩 시 1회)
  data/load.js              CSV 로드
  logic/constants.js        구간, 가중치, 태그 기준 등 PRD 상수
  logic/percentile.js       평균 순위 백분위
  logic/recommend.js        예산 검증, 필터, 점수, 태그, 기여 지표, 정렬
  logic/relax.js            후보 없음 처리 (완화안 1~4, 대안, 유사 크리에이터)
  ui/render.js, ui/format.js 결과·카드·빈 상태 렌더링
tests/                      브라우저에서 실행하는 로직 테스트 (PRD 수치·시나리오 검증)
```

## 구현 메모

- 백분위는 `(값이 더 작은 개수 + 같은 값 개수 × 0.5) ÷ 모집단 수`로 계산합니다. 모집단은 200명 전체를 구간(조회율은 플랫폼)별로 나눈 집단이고, 비용 지표만 이력 없는 크리에이터를 뺍니다.
- 매칭 점수는 정렬에만 쓰고 화면에는 보여주지 않습니다.
- 현재 데이터에는 없지만, 숫자 필드 결측·음수·형식 오류는 해당 지표만 중립값 0.5로 처리하고, ID·채널명이 없는 행은 제외합니다. 팔로워 수를 읽을 수 없는 크리에이터는 구간을 정할 수 없어 어떤 규모 조건에도 걸리지 않습니다.
